### Analysis
* **[문제 변환]**
    * 최적화 문제: 바위를 n개 제거했을 때, 바위 사이 거리의 최솟값 중 가장 큰 값은?
    * 결정 문제: 바위 사이의 최소 거리를 x 이상으로 유지할 때, 제거할 바위 수가 n개 이하인가?

* **[단조성 (Monotonicity)]**
    * 목표 거리 x가 커질수록 유지하기 위해 제거해야 하는 바위 수 f(x)는 단조 증가한다.
    * 결정 결과 f(x) <= n 은 [True, ..., True, False, ...] 형태의 단조성을 띤다.

* **[이진 탐색 방향 (Rightmost True 탐색)]**
    * f(x) <= n (가능) -> answer = x 저장 후 더 큰 거리 탐색 (left = mid + 1)
    * f(x) > n (불가능) -> 기준 거리를 줄여야 함 (right = mid - 1)

### How I solved
1. 주어진 rocks 배열 오름차순 정렬 ($O(M \log M)$)
2. 그리디 판별 함수 정의: 직전 지점과의 거리가 x 미만이면 바위 제거 카운트 증가, x 이상이면 기준점 갱신 (마지막 도착 지점 체크 필수)
3. $1$부터 `distance` 범위에서 이분 탐색 수행 ($O(M \log D)$)
4. 조건을 만족하는 `middle`을 `answer`로 갱신하며 최댓값(Rightmost True) 도출

### Key Takeaway
- 최적화 문제를 결정 문제로 전환하고, 판별 결과의 단조성이 보장될 때 Parametric Search를 적용할 수 있다.
- 판별 함수 내부에서는 "거리 조건을 만족하지 못하는 바위를 우선 제거"하는 그리디 접근이 최적해를 보장한다.
